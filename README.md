# street-fivem-skills

Skills for Claude Code (and other agents) from **Street Roleplay**, a FiveM server on
QBox + MRI. Each folder with a `SKILL.md` is one skill: rules and templates that came from
real changes on the server, written so another server's agent can apply them.

## Install

Tell your agent:

> Install the skills from https://github.com/welingtonivoivo-ctrl/street-fivem-skills following its INSTALL.md

## Skills

| Skill | What it does |
| --- | --- |
| [mri-appearance-favorites](mri-appearance-favorites/SKILL.md) | Favorite clothes in mri_Qappearance (star on each piece, favorites-only tab filter, saved per character) and the fix for the clothing grid ignoring the blacklist |

Format and rules follow [mri-fivem-skills](https://github.com/mri-Qbox-Brasil/mri-fivem-skills).
